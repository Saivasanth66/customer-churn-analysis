# Customer Churn Analysis

## 📌 Project Overview

An end-to-end **Customer Churn Analysis** project using **Python, SQL/MySQL, and Power BI** to analyze customer behavior, identify churn patterns, and generate business insights.

## 🎯 Objectives

- Analyze customer churn and customer behavior.
- Identify churn patterns across contracts, subscriptions, payment methods, and services.
- Analyze customer tenure, charges, revenue, and customer value.
- Build an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

**Python | Pandas | SQL | MySQL | Power BI | Excel | Machine Learning | Data Visualization**

## 🔄 Workflow

Raw Data
   ↓
Data Cleaning
   ↓
Exploratory Data Analysis
   ↓
SQL / MySQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights


## 📊 Key Analysis

- Churn by state and customer segments
- Contract and subscription analysis
- Payment method and internet service analysis
- Customer tenure and charges
- Customer value and revenue analysis

The processed dataset contains **492 customer records** with derived fields such as Tenure Group, Senior Flag, and Churn Flag.
